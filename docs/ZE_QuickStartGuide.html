App öffnen & anmeldenOuvrir l'app & s'authentifier

Öffne https://vob0x.github.io/Zeiterfassung. Melde dich mit Codename + Passwort an. Das Passwort wird verwendet, um deinen persönlichen Verschlüsselungsschlüssel abzuleiten — ein sicherer Standard ohne E-Mail-Verifikation. Beim ersten Login wird automatisch ein E2E-Verschlüsselungsschlüssel generiert und dein Profil in der Cloud gespeichert.

Ouvrez https://vob0x.github.io/Zeiterfassung. Identifiez-vous avec Codename + mot de passe. Le mot de passe est utilisé pour dériver votre clé de chiffrement personnelle — un standard sécurisé sans vérification par email. À la première connexion, une clé de chiffrement E2E est générée automatiquement et votre profil est stocké dans le cloud.

2

Stammdaten prüfenVérifier les données de base

Öffne den Verwaltung-Tab (5. Tab, ). Hier prüfst du, ob alle Stakeholder, Projekte, Tätigkeiten und die neuen 5 Formate (Einzelarbeit, Meeting, Telefonat, Workshop, Sonstiges) vorhanden sind. Fehlende Einträge kannst du sofort hinzufügen — sie werden über Supabase Realtime live mit dem Team synced.

Ouvrez l'onglet Gestion (5e onglet, ). Vous vérifiez que tous les mandants, projets, activités et les nouveaux 5 formats (Travail individuel, Réunion, Appel téléphonique, Atelier, Autres) sont présents. Vous pouvez immédiatement ajouter les entrées manquantes — elles sont synchronisées en temps réel avec l'équipe via Supabase Realtime.

3

Timer startenDémarrer le chrono

Im Timer-Tab (1. Tab, ): Wähle Stakeholder, Projekt, Tätigkeit und Format aus — das sind die 5 Dimensionen pro Eintrag (neu: Format ist jetzt pflicht). Mehrere Stakeholder? Multi-Select aktivieren! Mit Ctrl+K Fuzzy-Search oder Manueller Eintrag starten. Die DayRing zeigt deinen Fortschritt zum 8:24-Ziel live an.

Dans l'onglet Chrono (1er onglet, ) : sélectionnez mandant, projet, activité et format — ce sont les 5 dimensions par entrée (nouveau : format est maintenant obligatoire). Plusieurs mandants ? Activer Multi-Sélection ! Avec Ctrl+K recherche floue ou démarrez une saisie manuelle. Le DayRing affiche votre progression vers l'objectif 8:24 en temps réel.

4

Zeit buchenEnregistrer le temps

■ Stopp drücken — der Eintrag wird sofort mit AES-GCM-Verschlüsselung (immer aktiv, nicht optional) auf den Supabase-Servern gespeichert. Alle Textfelder sind bereits client-seitig verschlüsselt, bevor sie gesendet werden. Der Eintrag erscheint sofort in der Einträge-Übersicht und die DayRing aktualisiert sich live. Zum Bearbeiten: Eintrag anklicken, Änderungen werden automatisch synced.

Appuyez sur ■ Stop — l'entrée est immédiatement sauvegardée avec chiffrement AES-GCM (toujours actif, non optionnel) sur les serveurs Supabase. Tous les champs de texte sont déjà chiffrés côté client avant d'être envoyés. L'entrée apparaît immédiatement dans l'aperçu Entrées et le DayRing se met à jour en temps réel. Pour modifier : cliquez sur l'entrée, les modifications sont auto-synchronisées.

5

Team beitretenRejoindre l'équipe

Öffne den Team-Tab (4. Tab, ) → Team beitreten. Gib den 6-stelligen Invite-Code ein oder scanne den QR-Code. Danach siehst du alle Team-Daten, das Live-Dashboard mit Tagesübersicht, Auslastung pro Person, Stakeholder × Projekt-Matrix, Timeline und Excel-Export. Alle neuen Stammdaten vom Team werden automatisch zu dir synced.

Ouvrez l'onglet Équipe (4e onglet, ) → Rejoindre l'équipe. Saisissez le code d'invitation à 6 chiffres ou scannez le code QR. Ensuite, vous voyez toutes les données de l'équipe, le tableau de bord en temps réel avec aperçu quotidien, charge par personne, matrice mandant × projet, chronologie et export Excel. Toutes les nouvelles données de base de l'équipe sont automatiquement synchronisées.

Cloud & SicherheitCloud & Sécurité

Deine Daten werden automatisch in Supabase (Cloud) gespeichert und sind IMMER mit AES-GCM E2E-Verschlüsselung geschützt (nicht optional). Alle Textfelder werden client-seitig verschlüsselt, bevor sie übermittelt werden. Team-Sync erfolgt über Supabase Realtime in Echtzeit. Zusätzlich empfohlen:

Vos données sont automatiquement stockées dans Supabase (Cloud) et sont TOUJOURS protégées par chiffrement E2E AES-GCM (non optionnel). Tous les champs de texte sont chiffrés côté client avant transmission. La synchronisation d'équipe se fait en temps réel via Supabase Realtime. En complément :

Lokales BackupSauvegarde locale

Verwaltung → «Backup & Wiederherstellung». Download eines HTML-Backups aller verschlüsselten Einträge und Stammdaten für Offline-Zugriff, Archivierung oder schnelle Wiederherstellung.

Gestion → «Sauvegarde & Restauration». Téléchargez une sauvegarde HTML de tous les entrées chiffrées et données de base pour accès hors ligne, archivage ou restauration rapide.
