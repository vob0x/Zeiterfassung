Erste SchrittePremiers pas

1

Registrieren & AnmeldenS'enregistrer et se connecter

Öffne die App-URL im Browser (PWA funktioniert auf Handy und Desktop). Registriere dich mit E-Mail und Passwort — oder melde dich an, falls du bereits einen Account hast. Das Passwort wird zur Ableitung deines persönlichen Verschlüsselungsschlüssels verwendet. Alle deine Daten sind E2E-verschlüsselt.

Ouvrez l'URL de l'app dans votre navigateur (PWA fonctionne sur téléphone et bureau). Inscrivez-vous avec votre email et mot de passe — ou connectez-vous si vous avez déjà un compte. Le mot de passe sert à dériver votre clé de chiffrement personnelle. Toutes vos données sont E2E-chiffrées.

2

Team beitretenRejoindre une équipe

Gehe zum Team-Tab (5. Tab, ). Gib einen 6-stelligen Invite-Code ein oder scanne einen QR-Code. Der Team-Schlüssel wird über verschlüsselte Verbindung ausgetauscht. Stammdaten (Stakeholder, Projekte, Tätigkeiten) synchronisieren sich automatisch.

Allez à l'onglet Équipe (5e onglet, ). Entrez un code d'invitation de 6 caractères ou scannez un code QR. La clé d'équipe est échangée via une connexion chiffrée. Les données de base (mandants, projets, activités) se synchronisent automatiquement.

3

Timer startenDémarrer le chrono

Im Timer-Tab (): Wähle Stakeholder (Multi-Select), Projekt, Tätigkeit, Format und optional eine Notiz. Bis zu 8 parallele Task-Slots möglich. Starten über Schnellsuche-Bar oder Quick-Chips. Timer synchronisiert sich echtzeit-übergreifend über alle Geräte.

Dans l'onglet Chrono () : sélectionnez mandant (multi-sélection), projet, activité, format et optionnellement une note. Jusqu'à 8 Task-Slots en parallèle. Lancez via la barre de recherche rapide ou Quick-Chips. Le chrono se synchronise en temps réel sur tous vos appareils.

4

Zeit buchenEnregistrer le temps

Klick auf ■ (Stop) → Eintrag wird sofort gespeichert und synchronisiert. Oder nutze «Manuell Eintragen» für rückwirkende Einträge (Datum, Start, Ende). Mit dem «Feierabend»-Button werden alle laufenden Timer gestoppt.

Cliquez sur ■ (Stop) → l'entrée est sauvegardée et synchronisée immédiatement. Ou utilisez «Saisie manuelle» pour des entrées antérieures (date, début, fin). Le bouton «Fin de journée» arrête tous les chrono actifs.

5

Dashboard & Auswertung nutzenUtiliser le tableau de bord

Dashboard-Tab (): KPIs, Zeitverlauf-Chart, Stakeholder × Projekt Heatmap. Team-Tab: Tagesübersicht, Projekt × Person Matrix, Workload-Charts. Erkenne schnell, wie die Zeit verteilt ist.

Onglet Tableau de bord () : KPIs, graphique de progression, heatmap mandant × projet. Onglet Équipe : aperçu quotidien, matrice projet × personne, graphiques de charge. Voyez rapidement comment le temps est réparti.

Hinweis: Dein Passwort ist dein Verschlüsselungsschlüssel. Speichere es sicher auf. Wenn du es verlierst, können deine Daten nicht wiederhergestellt werden. Important : Votre mot de passe est votre clé de chiffrement. Gardez-le en sécurité. Si vous le perdez, vos données ne peuvent pas être récupérées.

Backup & SicherheitSauvegarde & Sécurité

Toutes les données sont E2E-chiffrées (AES-256-GCM). Synchronisation automatique via Supabase Cloud. En complément :

JSON-Backup exportierenExporter une sauvegarde JSON

Verwaltung → «JSON-Backup exportieren». Enthält alle verschlüsselten Einträge, Stammdaten und Einstellungen. Speichere es offline an einem sicheren Ort.

Gestion → «Exporter sauvegarde JSON». Contient tous les entrées chiffrées, données de base et paramètres. Sauvegardez-le hors ligne à un endroit sûr.
