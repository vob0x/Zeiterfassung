1. Ueberblick & Systemanforderungen1. Vue d'ensemble & Configuration requise

Zeiterfassung ist eine Progressive Web App (PWA), die auf GitHub Pages gehostet wird. Sie funktioniert auf allen modernen Browsern und Geraeten ohne lokale Installation und synchronisiert alle Daten ueber Supabase mit End-to-End-Verschluesselung (AES-256-GCM).

Saisie du Temps est une Progressive Web App (PWA) hebergee sur GitHub Pages. Elle fonctionne sur tous les navigateurs et appareils modernes sans installation locale et synchronise toutes les donnees via Supabase avec chiffrement de bout en bout (AES-256-GCM).

8. Verschlusselung & Sicherheit8. Chiffrement & Securite

Alle Daten sind mit AES-256-GCM End-to-End-verschluesselt – immer aktiv, nicht optional.

Toutes les donnees sont chiffrees de bout en bout avec AES-256-GCM - toujours actif, non optionnel.

Schluesselarten

Types de cles

Personal Key

Cle personnelle

Abgeleitet aus dem Passwort (PBKDF2), gespeichert in der Browser-Session. Wird zum Verschluesseln/Entschluesseln persoenlicher Daten verwendet.

Derivee du mot de passe (PBKDF2), stockee dans la session du navigateur. Utilise pour chiffrer/dechiffrer les donnees personnelles.

Team Key

Cle d'equipe

Wird vom Team-Creator generiert, verschluesselt ueber den Einladungscode ausgetauscht, von Beitrittenden entschluesselt und personal-verschluesselt in der DB gespeichert.

Generee par le createur de l'equipe, echangee chiffree via le code d'invitation, dechiffree par ceux qui adhesent et stockee personellement-chiffree dans la BD.

Verschluesselbare Felder

Champs chiffrables

Stakeholder, Projekt, Taetigkeit, Format, Notiz sind VERSCHLUESSELT. Numerische Felder (Dauer, Daten, Zeiten) sind NICHT verschluesselt.

Intervenant, Projet, Activite, Format, Note sont CHIFFRES. Les champs numeriques (duree, dates, heures) ne sont PAS chiffres.

Ohne Passwort kein Zugriff auf verschluesselte Daten! Passwort sicher aufbewahren.
Sans mot de passe, pas d'acces aux donnees chiffrees! Garder le mot de passe en securite.

9. Multi-Device Sync9. Synchronisation multi-appareils

Melden Sie sich mit demselben Konto auf mehreren Geraeten an (Telefon + Desktop). Alle Eintraege und laufenden Timer synchronisieren sich ueber Supabase Realtime (sofort) mit Polling-Fallback (30-60s).

Connectez-vous avec le meme compte sur plusieurs appareils (telephone + bureau). Tous les entrees et minuteurs en cours se synchronisent via Supabase Realtime (instantane) avec repli de sondage (30-60s).

Server-Clock-Anchoring

Ancrage de l'horloge serveur

Timer-Status wird mit der Server-Zeit verankert, um Drift zwischen Geraeten mit unterschiedlichen Systemuhren zu verhindern.

Le statut du minuteur est ancre a l'heure du serveur pour eviter la derive entre les appareils avec des horloges systeme differentes.

Visibility-Change Handler

Gestionnaire de changement de visibilite

Beim Zurueckkehren zur App aus dem Hintergrund werden Daten sofort aktualisiert.

Lorsque vous revenez a l'application a partir de l'arriere-plan, les donnees sont immediatement actualisees.
