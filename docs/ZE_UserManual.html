Was ist Zeiterfassung?

Qu'est-ce que Zeiterfassung?

Zeiterfassung ist eine moderne Progressive Web App (PWA) für präzise, verschlüsselte Zeitleistung. Sie können Aktivitäten nach Stakeholder, Projekt, Tätigkeit und Format kategorisieren, mehrere Timer parallel laufen lassen und Ihr Team in Echtzeit überwachen — all mit vollständiger End-to-End-Verschlüsselung (AES-GCM) auf der Clientseite.

Zeiterfassung est une Progressive Web App (PWA) moderne pour l'enregistrement du temps précis et chiffré. Vous pouvez catégoriser les activités par partie prenante, projet, activité et format, exécuter plusieurs minuteurs en parallèle et surveiller votre équipe en temps réel — avec chiffrement de bout en bout (AES-GCM) complet côté client.

Technische Architektur

Architecture technique

Frontend: React + TypeScript (vite)
Backend: Supabase PostgreSQL + Auth
Verschlüsselung: Web Crypto API (AES-256-GCM)
Storage: sessionStorage (Schlüssel), Supabase (verschlüsselt)

Backup & Sicherheit

E2E-Verschlüsselung, Cloud-Backup, Key Management

End-to-End Verschlüsselung (AES-GCM)

Alle Ihre Daten werden mit AES-256-GCM verschlüsselt, bevor sie den Browser verlassen.

Personal Key

Abgeleitet von Ihrem Passwort (PBKDF2). Persönliche Daten.

Team Key

Eindeutig pro Team. Gemeinsame Daten. Alle Mitglieder haben diesen Schlüssel.

Key Storage

  • Personal Key: sessionStorage (gelöscht bei Tab-Schließung)
  • Team Key: sessionStorage (gelöscht bei Tab-Schließung)
  • Passwort: NIEMALS gespeichert oder an Server gesendet
Passwort-Vergessen: Wenn Sie Ihr Passwort vergessen, können Sie Ihre Daten nicht wiederherstellen.

Fehlerbehebung

Häufige Probleme und Lösungen

Timer startet nicht

  • Lösung 1: Aktualisieren Sie die Seite mit F5
  • Lösung 2: Stellen Sie sicher, dass JavaScript aktiviert ist
  • Lösung 3: Löschen Sie Browser-Cookies

Sync-Fehler ("Kategorien zeigen -")

Wenn Ihr Verschlüsselungsschlüssel nicht geladen wurde:

1
Melden Sie sich ab
2
Melden Sie sich erneut an mit korrektem Passwort

QR-Code Scan funktioniert nicht

  • Lösung 1: Stellen Sie sicher, dass Sie gutes Licht haben
  • Lösung 2: Halten Sie das Gerät ruhig
  • Fallback: Verwenden Sie den 6-stelligen Code

Glossar

Alle Begriffe erklärt

Codename
Ihr eindeutiger Benutzer-ID. Beispiel: john.doe, team_lead.
Stakeholder
Person oder Organisation, die von einer Aktivität profitiert. Multi-Select in Einträgen.
Projekt/Produkt
Größerer Arbeitszusammenhang. Single-Select in Einträgen.
Tätigkeit
Art der Arbeit. Beispiele: Coding, Testing, Design. Single-Select.
Format
Wie wird die Arbeit durchgeführt: Einzelarbeit, Meeting, Telefonat, Workshop.
Personal Key
Verschlüsselungsschlüssel, abgeleitet von Ihrem Passwort. Verschlüsselt persönliche Daten.
Team Key
Eindeutige Schlüssel pro Team. Verschlüsselt gemeinsame Daten.
AES-GCM
Advanced Encryption Standard mit Galois/Counter Mode. 256-Bit Schlüssellänge.
Multi-Stakeholder
Eintrag mit mehreren Stakeholdern. Dauer wird einmal gezählt (Wanduhrenzeit).
DayRing
Visuelle Anzeige des täglichen Fortschritts. Grün = unter 8h24, Gold = 8h24, Rot = über 8h24.
Fuzzy Search
Intelligente Suchfunktion mit Frecency-Ranking (Häufigkeit + Rezenz).
Invite Code
6-stelliger alphanumerischer Code zur Team-Beitrittung. Beispiel: AB12CD.
Cyber Theme
Dark Mode mit neon cyan (#00e5ff) Akzenten und Gold (#c9a962) Highlights.
PWA (Progressive Web App)
Web-Anwendung, die wie eine native App installiert werden kann. Funktioniert offline.
IndexedDB
Browser-Datenbank für offline Zwischenspeicherung von verschlüsselten Daten.
sessionStorage
Browser-Speicher, der gelöscht wird wenn der Tab geschlossen wird. Speichert Verschlüsselungsschlüssel.
UnlockScreen
Bildschirm nach Tab-Schließung. Sie müssen Passwort erneut eingeben zur Schlüsselableitung.
